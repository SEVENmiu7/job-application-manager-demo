# 求职投递管理器｜面试演示版

一个用于管理求职投递进度的全栈应用。项目提供看板、列表、岗位采集、进度更新和下一步安排等能力。

> 本仓库是面试演示副本，只包含虚构公司、虚构岗位和演示备注。它使用独立的飞书妙搭应用和数据库，不与个人正式投递数据共享记录。

## 核心功能

- 五阶段投递看板，支持拖动推进和重点置顶。
- 投递列表、搜索、筛选、分页、状态快捷修改和材料详情抽屉。
- 工作地点支持多选、地区分组搜索和自定义录入，可记录跨城市或远程岗位。
- 岗位链接采集与结构化信息提取。
- 面试流程时间线，可查看并编辑各阶段发生时间。
- 投递时间按中国时区稳定显示，避免跨时区日期偏移。
- 当前进度、下一步安排和备注管理。
- 新增与编辑页面采用分段式信息结构，适合现场演示完整录入流程。
- 首次访问自动生成 15 条虚构演示数据。
- 用户之间的演示记录相互隔离。

## 技术栈

- React 19 + TypeScript + Vite
- NestJS 10
- PostgreSQL + Drizzle ORM
- Tailwind CSS + shadcn/ui
- 飞书妙搭 full-stack 运行时

## 目录结构

```text
client/     React 前端
server/     NestJS 后端和数据库迁移
shared/     前后端共享类型
scripts/    本地开发和质量检查脚本
test/       自动化测试
```

## 本地开发

环境要求：Node.js 22+ 和 npm 10+。

```bash
npm install
npm run dev
```

妙搭本地开发需要由平台下发 `.env.local`。仓库只提供不含密钥的 `.env.example`，不提供真实数据库连接信息。

## 演示数据

演示数据定义在 `server/modules/application/demo-applications.ts`。当当前用户没有任何投递记录时，后端会自动创建一组样例。删除全部记录后刷新页面，即可恢复初始演示数据。

## 隐私与公开仓库

仓库通过 `.gitignore` 排除 `.env`、`.env.local`、日志、依赖目录和构建产物。提交前建议运行：

```bash
git status
git diff --cached
git ls-files
```

请勿将真实简历、投递记录、Token、密码或数据库地址提交到公开仓库。
